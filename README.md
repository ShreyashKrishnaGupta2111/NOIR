# NOIR — QR Restaurant Ordering Website 🍽️

A premium, mobile-first restaurant menu and ordering website built using HTML, CSS, and JavaScript.

## Features

- Responsive restaurant website
- Premium dark and gold user interface
- Food and beverage menu
- Category filters and search
- Vegetarian and non-vegetarian indicators
- Food images, descriptions, and prices
- Interactive shopping cart
- Quantity controls
- Automatic bill calculation in INR
- Table number selection
- Special instructions
- Demo checkout and order preview
- QR-compatible table-specific links
- GitHub Pages deployment

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash food photography
- GitHub Pages

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Browse the menu and add items to the cart.

## Deploy on GitHub Pages

1. Upload all project files to your GitHub repository.
2. Open Settings → Pages.
3. Select Deploy from a branch.
4. Choose `main` and `/(root)`.
5. Click Save.

Your website will be published at:

`https://YOUR-USERNAME.github.io/noir-qr-restaurant/`

## Table QR Codes

Create table-specific links after publishing:

- `?table=1`
- `?table=2`
- `?table=3`

Append the relevant parameter to your website URL and generate a QR code for each table.
